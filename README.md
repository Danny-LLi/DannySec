Dies ist das offizielle Repository für mein persönliches Portfolio. Es dient nicht nur als Visitenkarte für meine Arbeit als **Security Engineer & Penetration Tester**, sondern ist selbst ein Beispiel für modernes Software Engineering mit Fokus auf Performance, Clean Code und Sicherheit.

## 🚀 Tech Stack

Das Projekt wurde mit einem Fokus auf Geschwindigkeit und Typsicherheit entwickelt:

| Core | UI / UX | Tools |
| :--- | :--- | :--- |
| **Vite** (Build Tool) | **React 19** | **TypeScript** |
| **Tailwind CSS** | **shadcn/ui** | **Framer Motion** (Animations) |
| **Lucide React** (Icons) | **TanStack Query** | **Zod** (Validation) |

---

## ⚡ Highlights der Implementierung

* **Multilingual (i18n):** Volle Unterstützung für Deutsch und Englisch.
* **Performance-Optimiert:** Nutzung von `Framer Motion` mit `useInView` für ressourcensparende Animationen.
* **Responsive Design:** Optimiert für alle Endgeräte (Mobile-First-Ansatz).
* **Security by Design:** Saubere Trennung von Komponenten und strikte Typisierung durch TypeScript.
